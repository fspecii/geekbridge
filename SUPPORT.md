# Getting help

GeekBridge is a volunteer-run free-software project (GPL-3.0-or-later). There is no commercial support and no guaranteed
response time.

1. **Read the [user guide](docs/user-guide.md).** It has symptom-keyed troubleshooting (pairing fails, phone not found,
   transfers, calls, clipboard, battery and OEM background limits). [Omarchy / Hyprland setup](docs/omarchy.md) and
   [Android power](docs/android-power.md) cover the two most common sources of trouble.
2. **Collect a report.** On the computer run `geekbridge-ctl diagnose`; on the phone open **Diagnostics & about >
   Copy report**. Both are redacted, but read them and remove anything personal before sharing.
3. **Open an issue** at <https://github.com/fspecii/geekbridge/issues> with the bug-report form. Include phone model,
   OEM and Android version, desktop OS, and the report. Never paste phone numbers, names, message text, contacts,
   calendar entries, IP addresses, pairing codes or QR links.
4. **Security problems** are not public issues. Follow [SECURITY.md](SECURITY.md).
5. **Want to fix it yourself?** See [CONTRIBUTING.md](CONTRIBUTING.md) and [ARCHITECTURE.md](ARCHITECTURE.md).

GeekBridge is an independent implementation of the KDE Connect protocol and is not affiliated with the KDE project;
please do not ask KDE for help with GeekBridge.
