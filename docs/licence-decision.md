# Licence decision

**Decided 2026-11-02 by the owner: GeekBridge is licensed under `GPL-3.0-or-later`, the repository `fspecii/geekbridge`
is made public, and releases are built locally.** This page records why and what was done. It is an engineering
summary, not legal advice.

## Why GPL-3.0-or-later

* The ecosystem we interoperate with (KDE Connect, GSConnect, Valent) is GPL. A GPL licence lets KDE-side developers
  contribute freely and keeps forks open.
* Every dependency is compatible: all third-party Rust crates are under permissive licences (MIT, Apache-2.0, BSD, ISC,
  Zlib, Unicode-3.0, Unlicense, 0BSD, CC0, BSL-1.0, CDLA-Permissive-2.0). Apache-2.0 is compatible with GPL-3.0 (not with
  GPL-2.0-only, which is why the licence is "3.0 or later"). The only copyleft string anywhere is `r-efi`
  (`MIT OR Apache-2.0 OR LGPL-2.1-or-later`), where the permissive alternative applies. The Android app has no
  third-party runtime code besides the Kotlin standard library (Apache-2.0).
* Trade-off accepted: closed redistribution and the Apple App Store are off the table (GPL-3 conflicts with its terms);
  relicensing later needs every contributor's consent, which is why contributions come with a DCO sign-off
  ([CONTRIBUTING.md](../CONTRIBUTING.md)).

## Relationship to KDE Connect

GeekBridge speaks the KDE Connect protocol so a stock KDE Connect phone or desktop can talk to it. It is an independent
implementation written from observed protocol behaviour (port numbers, JSON field names, state names, the verification-key
recipe, packet captures from stock builds in `crates/bridge-kde/tests/fixtures/`). No KDE Connect source is included or
translated. The audit compared about 94,000 distinctive lines (55+ characters) from reference clones against every tracked
source file; the only matches were unavoidable boilerplate (`use std::...`, trait signatures, Android permission lines and
XML namespaces). With a GPL licence, incorporating KDE code later would be allowed, but the rule stays: do not paste or
mechanically translate it without recording it. "KDE Connect" is used nominatively ("compatible with KDE Connect") and
never in the product name or icon; the project is not affiliated with KDE.

## Fonts

egui's default fonts include `Ubuntu-Light` (Ubuntu Font Licence 1.0, which the FSF lists as free but GPL-incompatible).
The `default_fonts` feature of `eframe` is now **off**. The desktop apps embed only OFL-1.1 and MIT-style fonts from
`third_party/fonts/` (Noto Sans subset, Noto Emoji, Hack, emoji-icon-font); see its README for licences and the subsetting
command. Glyph coverage is unchanged for Latin, Latin Extended, Greek and Cyrillic, and the system UI font is still
preferred when present. A unit test (`embedded_fonts_cover_latin_greek_cyrillic_and_monospace`) guards coverage.
